WorldNarration sends only public fictional identity, the source record, previous opinions and limited memory to the configured cloud provider. It can decline to post. Generated opinions are labeled and linked to their source; they do not create games, transfers, videos, streams, friendships, balance values or economic actions. Content ideas are ideas, not claims that media already exists. No model gets action tools or private orders, payroll, credentials, emails or human account details. Human-written community posts are not narration sources.

Calls have durable actor/source reservations, at most four attempts per source, eight-hour author cooldowns, one call per five-minute tick, six calls/hour and a default 48/day. Failures and silence count toward the budget. Recent posts and expressed-interest memory are retained. Validation rejects malformed/incomplete output, missing exact source excerpts, unsupported numeric tokens, links/markup and near-duplicate wording. These constraints reduce repetition and unsupported claims; they do not prove perfect factuality or natural character behavior. A 401/403/429 pauses that provider for an hour; 402 pauses it indefinitely for owner review. Future provider errors retain a credential-redacted bounded diagnostic in the server cache. There is no canned character fallback and no automatic switch to a paid provider. Real provider behavior and longer-run diversity require live acceptance.

## Free provider configuration

Use a Google AI Studio API key belonging to a project on the free tier. Google currently lists free input/output for Gemini 3.1 Flash-Lite, with quotas; free-tier submissions may be used to improve its products. Check the [official pricing](https://ai.google.dev/gemini-api/docs/pricing), [model](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite) and [OpenAI-compatible endpoint](https://ai.google.dev/gemini-api/docs/openai) when deploying. A key from a paid project follows that project's billing; this application cannot determine or change its billing tier.

Set these privately in `.env.evolution.local` for Docker, or the API environment for another deployment:

```dotenv
WORLD_NARRATION_PROVIDER=gemini
WORLD_NARRATION_MODEL=gemini-3.1-flash-lite
WORLD_NARRATION_GEMINI_API_KEY=<private Google AI Studio key>
WORLD_NARRATION_ENABLED=true
WORLD_NARRATION_DAILY_CALLS=48
```

The existing `WORLD_NARRATION_API_KEY` is reserved for an explicitly selected OpenAI provider and is never sent to Google. Default narration is disabled. Configuration is passed to API/worker/scheduler through compose. Refresh those three services after private changes; do not refresh the match/history/ML/avatar workers for narration. Never print resolved compose configuration or keys. Do not create paid accounts, enable billing or purchase credits as an automatic fallback.
