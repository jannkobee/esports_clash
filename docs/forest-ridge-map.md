# Forest citadel and raised ridge — implemented, unverified

The user replaced the swamp request with a more detailed setting and a lane that looks like highground. The current direction is forested lowlands around a raised stone ridge, with warm sanctuary courtyards at each end. This supersedes the untested wetland revision in `stone-sanctuary-map.md`.

The lane/base plateau has 32 units of render height. `arenaElevation.ts` shares the height/shoulder/ramp profile between the subdivided ground shader and CPU grounding. Eight wider ramps are marked with low paired waystones and worn steps; the remaining shoulders are sloped and remain traversable. The underlay for flat tactical rendering disables height displacement. Solid base plinths close the exposed world-edge sides.

Grounding is integrated across champions, creatures, minions, structures, wards, labels, melee contact targets, cliffs, static props and ambient particles. `threeAbilityEffects.ts` accepts an optional surface-height callback; the default is flat for the model studio. Beams lift each endpoint; low ring outlines crossing a slope use surface-following segments. Weapon socket copies use surface-relative coordinates before the VFX layer reconstructs their heights, so muzzle flashes/projectile origins/trails are not lifted twice. Weapon, AoE and interpolation behavior still require actual visual inspection.

The lowlands use forest soil, moss, leaf litter, dry camp trails, flowers/ferns and camp clearings. Water ripples, foam, watery coloring, reeds and lily rafts are removed. Slow canopy shade and drifting leaves borrow match time. Existing curved camp cliffs/roots remain, with additional carved fragments, fallen timber, ramp markers and guardian monuments on boss rear walls. Tall boundary forest and the actual concealment brush remain distinct from low decorative ground plants.

The cozy cabin/merchant bases and small healing shrines remain. Creeps still spawn at the Nexus, skirt the middle barracks at ordinary speed and join the lane. Actual healing/shop/recovery/beam rules and barracks empowerment remain. Highground is a rendering feature only: no extra collider, vision rule, range/damage advantage, movement modifier, AI change or gameplay height coordinate is introduced. Existing tower/Nexus legality, retreat, attribution, objective contests, anti-spin, names, default mute, avatar/import selections and offline ML status remain protected.
