# Esports Clash avatar art revision 4

34 self-contained, meter-scale glTF 2.0 binaries. Existing 17-joint animation hierarchy and Idle/Walk/Attack/Cast clips are preserved. Textured artist anatomy and 14 fitted scout outfits use Quaternius CC0 Standard assets; original game costume and equipment remain alongside them. Other 11 roster designs continue loading `avatars-v2`.

Sources: https://quaternius.com/packs/universalbasecharacters.html and https://quaternius.com/packs/modularcharacteroutfitsfantasy.html — CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/ . Full notices, source hashes, editable Blender examples and rebuild instructions are in the repository's `art/` directory. `manifest.json` identifies every output, hash and source choice.

These are an anatomy/clothing upgrade with shared bases; individual face sculpting, costume polish, LOD/compression and animation work remain. Historical v2 files and ZIP are retained as earlier artifacts.
