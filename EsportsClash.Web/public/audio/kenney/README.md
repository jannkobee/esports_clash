# Skill audio provenance

The 27 `.ogg` files in this directory are unmodified selections from three
Kenney packs. All three packs contain a `License.txt` granting Creative Commons
Zero (CC0) use in personal and commercial projects. Credit is appreciated but
not required. The filenames have only been prefixed with their source pack.

- `rpg-*`: [RPG Audio](https://kenney.nl/assets/rpg-audio)
- `impact-*`: [Impact Sounds](https://kenney.nl/assets/impact-sounds)
- `sci-*`: [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds)

License: https://creativecommons.org/publicdomain/zero/1.0/

These are original game effects made from CC0 recordings. No audio was taken
from the games that inspired the avatars.
