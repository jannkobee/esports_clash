# Country flags

4:3 SVG flags and country metadata from [flag-icons 7.3.2](https://www.npmjs.com/package/flag-icons/v/7.3.2), under the included MIT license. Only 249 ISO entries are bundled. Assets are served locally.

Package SHA-256: 9477c5252afe0e99dd2d4408b664c83e7c7c80785c7983751d5c7a020198a731

Country-to-region containment uses [Unicode CLDR 47](https://github.com/unicode-org/cldr-json/tree/47.0.0/cldr-json/cldr-core/supplemental), with the included Unicode license. The generated country-directory JSON is identical in the API and frontend; existing database names and IDs are retained.
