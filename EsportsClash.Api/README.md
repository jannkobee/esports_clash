# Esports Clash API

Laravel 13 API for authenticated cloud persistence. The arena simulation remains
in the React client; this service owns player identity, club snapshots, and
immutable match reports.

## Local setup

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

The default local database is SQLite at `database/database.sqlite`. To use
MySQL or PostgreSQL, set the ordinary `DB_*` environment values before running
the migration command.

Set the frontend's `VITE_API_URL` to `http://127.0.0.1:8000/api/v1` using
`EsportsClash.Web/.env`. The React client remains fully usable without this
variable and continues to use browser storage until a cloud session is created.

## API surface

- `POST /api/v1/auth/register` — create an account and return a Sanctum bearer token.
- `POST /api/v1/auth/login` — return a bearer token.
- `DELETE /api/v1/auth/token` — revoke the current token.
- `GET|PUT /api/v1/club` — load or replace the authenticated user's roster and Starting 5 snapshot.
- `GET|POST /api/v1/matches` — page match summaries or save a complete replay report.
- `GET /api/v1/matches/{matchReport}` — retrieve one owned replay.

Tokens have scoped abilities. Club requests cannot access another user's club;
match reports are owned by their creator and are stored as submitted replay
payloads alongside queryable outcome metadata.
